# 📌 About The Project

**Stock Portfolio Tracker Pro** is a desktop-based stock portfolio management application developed using **Python and Tkinter**.

The application helps users manage stock holdings, calculate portfolio investment values, view portfolio statistics, search holdings, and understand portfolio distribution through visualizations.

This project was developed as part of the **CodeAlpha Internship**.

---

# ✨ Features

## 📊 Portfolio Management

- ➕ Add stocks to the portfolio
- ✏️ Edit existing stock quantities
- 🔄 Update stock holdings
- 🔁 Handle duplicate stocks
- 💰 Calculate total investment
- 📦 Calculate total shares
- 📊 Display individual stock values

## 🔎 Search & Filtering

- Search stocks quickly
- Filter portfolio holdings
- Easily locate specific stocks

## 📈 Portfolio Analytics

- Total investment statistics
- Number of holdings

- Average holding value

- Portfolio distribution
- Donut/pie chart visualization

## 💾 Data Management
