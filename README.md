# 📈 Stock Portfolio Tracker Pro

A professional and colourful desktop Stock Portfolio Tracker built using Python and Tkinter.

## ✨ Features

- 📊 Donut portfolio allocation chart
- 💰 Total investment statistics
- 📦 Total number of holdings
- 🔢 Total number of shares
- 📈 Average holding value
- 🔎 Search and filter holdings
- ➕ Add investments
- 🔄 Automatic duplicate-stock merging
- ✏️ Edit selected holdings
- 🗑️ Remove holdings
- 🧹 Clear portfolio
- 🌓 Light and dark themes
- 💾 TXT report export
- 📄 CSV export
- 🖥️ Custom application icon
- ⌨️ Keyboard Enter-key support
- ⚠️ Input validation
- ✅ Automated unit testing

---

## 🛠️ Technologies

- Python 3
- Tkinter
- ttk
- Dictionary
- Functions
- Exception handling
- File handling
- CSV
- unittest

No external Python packages are required.
